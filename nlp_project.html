PROJECT_ID: RMP_NLP_ANALYSIS_05

Project Objective

The objective was to extract and analyze large-scale student feedback data from Rate My Professors (RMP) to identify key themes in reviews and understand how they influence professor quality ratings. The project combined web scraping, natural language processing (NLP), and machine learning to generate actionable insights from unstructured text.

Technical Overview

This project utilized automated web scraping via RSelenium to collect reviews from the Economics Department at Iowa State University. The data was processed using NLP techniques and analyzed using Structured Latent Dirichlet Allocation (sLDA).

The analysis linked textual feedback with numerical ratings, quantifying how specific themes (like course difficulty or lecture clarity) correlate with positive or negative student perceptions.

Data Collection & Modeling

  • 01.
    Scraping: Automated browser interaction using RSelenium to handle dynamic RMP content.
  • 02.
    Preprocessing: Cleaning 1,856 reviews via language detection, tokenization, and stop-word removal.
  • 03.
    sLDA Analysis: Modeled 8 latent topics using ratings as supervised annotations to guide topic discovery.

Outcomes & Contributions

  • Built an end-to-end data pipeline transforming unstructured web data into interpretable insights.

  • Identified key drivers of student satisfaction (e.g., helpfulness) vs. dissatisfaction (e.g., disorganization).

  • Demonstrated the value of data-driven analysis in educational assessment and decision-making.
