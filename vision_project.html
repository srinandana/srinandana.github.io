PROJECT_ID: DL_PERCEPTION_07

Project Objective

The objective was to compare vision-based perception modules for autonomous vehicles, specifically focusing on accurately segmenting roads, lanes, and surrounding objects. The goal was to evaluate real-time semantic and instance segmentation models for deployment in cyber-physical systems (CPS) and resource-constrained environments.

Technical Overview

This project focuses on road scene understanding using deep learning–based image segmentation. Multiple state-of-the-art architectures were implemented: Fast-SCNN for speed, SegFormer for accuracy, and YOLOv8 for instance detection.

Trained on the CityScapes dataset (5,000+ urban images), the system balances segmentation accuracy with computational efficiency, aiming for real-time feasibility in autonomous driving.

Models Implemented

Fast-SCNN

Lightweight CNN optimized for embedded/edge devices. Fast inference.

SegFormer

Transformer-based. Captures long-range context for high-quality masks.

YOLOv8

Real-time instance segmentation for dynamic object tracking (cars/pedestrians).

SAM

Segment Anything Model. Zero-shot flexibility for novel objects.

Key Results

  • Fast-SCNN: Demonstrated strong potential for real-time deployment on embedded platforms.

  • SegFormer: Provided superior semantic segmentation quality for continuous classes like roads.

  • YOLOv8: Excelled at detecting dynamic objects, critical for obstacle avoidance.
