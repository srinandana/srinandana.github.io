PROJECT_ID: IOT_CYCLE_LOG_01

Project Objective

The objective was to design and develop a low-cost, automated cycle-counting system for endurance testing of mechanical components. The system aims to accurately track operational cycles while providing both local visualization and real-time remote data access for seamless test monitoring and documentation.

Technical Overview

The system is built around an RFID-based sensing mechanism integrated with a NodeMCU (ESP8266) microcontroller. An RFID tag is mounted on the moving component, while a stationary reader detects each pass to register a cycle.

The microcontroller processes the signal, increments the count on a local LED display, and simultaneously pushes the data to the cloud via Wi-Fi for remote analytics.

System Architecture

  • 01.
    Sensing: Contactless RFID detection ensures wear-free cycle counting.
  • 02.
    Processing: NodeMCU handles logic to debounce signals and prevent duplicate reads.
  • 03.
    Cloud Integration: Real-time API uploads to Google Sheets for accessible logging.

Outcomes & Contributions

  • Fabricated a robust, ready-to-use monitoring device for workshop environments, eliminating manual tracking errors.

  • Enabled real-time remote data sharing, significantly improving workflow for test supervisors.

  • Demonstrated practical application of embedded systems, IoT, and test automation in mechanical reliability contexts.
