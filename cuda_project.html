PROJECT_ID: HPC_THERMAL_SIM_06

Project Objective

The objective was to implement a GPU-accelerated solver for the two-dimensional transient heat equation using CUDA. This project aimed to demonstrate how parallel computing significantly reduces computation time for large-scale thermal simulations, comparing CPU versus GPU performance while maintaining numerical accuracy.

Technical Overview

This project models transient heat conduction through a square plate using the 2D heat equation (analogous to Fick’s second law). The governing PDE was discretized using an explicit finite difference method.

A CUDA-based parallel implementation was developed where each GPU thread computes the temperature update for a specific grid point. This massive parallelism allowed for efficient execution of large-scale simulations involving thousands of nodes and time steps.

Modeling & Numerical Method

  • 01.
    Domain: 0.2m × 0.2m Square Plate.
  • 02.
    Boundary Conditions: Left wall at 1000 K, Right wall at 100 K.
  • 03.
    Solver: Explicit Finite Difference Method with 20,000 iterative time steps.

Outcomes & Contributions

  • Developed an end-to-end GPU-accelerated PDE solver, from mathematical formulation to CUDA kernel execution.

  • Demonstrated significant speedup using GPU computation compared to CPU execution, particularly for fine grid resolutions.

  • Gained hands-on experience with CUDA concepts: thread grids, block dimensions, and device memory management.
